Proyectos

  • Sistema de administración de prácticas profesionales: Este es un sitio web donde las empresas y estudiantes pueden ver información sobre las prácticas profesionales y registrarse para participar. También tiene un panel de administrador para asignar estudiantes a empresas y administrar toda la información.
  • Sistema de rifa: Se creo un sistema donde usuarios pueden registrarse en línea para participar en una rifa para ganar ropa creada para por estudiantes del programa de diseño y gestión de la moda. También cuenta con panel de administradores para generar códigos de rifa y seleccionar un ganador.
